# XefwwRecoil

## Installation

### Easy Install (Recommended)
1. Download or clone the repo.
2. Double-click `Install_Requirements.bat` - it will install Python packages automatically.
3. Double-click `Start_XefwwRecoil.bat` to launch the app.

### Manual Install
1. Install requirements: `pip install pyautogui opencv-python mss numpy pynput keyboard`
2. Run: `python XefwwRecoil.py`

## Functions

See the app for full features. Default hotkey: **F1** to toggle recoil.
